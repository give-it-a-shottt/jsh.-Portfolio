## 면접 예상 질문
- 디자인 시스템을 만들 때 값을 왜 전부 변수(토큰)로 묶었나요? 테마·라운드·글꼴을 모드로 나눈 기준은 무엇인가요?
  - 답: 값을 전부 변수로 묶어 두면 나중에 값의 기준이 흔들리지 않고, 협업할 때도 통일성이 생긴다고 봤어요. 글꼴은 어떤 사이트를 맡을지 몰라서 고딕 계열 3개와 세리프 계열 1개를 준비했어요. 라운드와 테마는 값마다 분위기가 달라서, 사이트 분위기에 맞게 골라 쓰려고 모드로 나눴어요. (사용자 구술)
- 수업 자료가 없는 컴포넌트(푸터, 빈 상태 등)는 무엇을 기준으로 설계했나요?
  - 답: 기존 사이트들을 조사해서 대표값을 뽑아 설계했어요. (사용자 구술)
- 이 시스템이 실제로 쓸 만한지 어떻게 검증했나요?
  - 답: FLASEEK에는 적용하지 않았어요. 컴포넌트만으로 조립한 샘플 화면(27번 페이지)으로 점검했어요. (사용자 구술)
