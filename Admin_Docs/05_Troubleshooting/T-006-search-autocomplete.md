# T-006 "디장"·"ㄷㅈㅇ"에 자동완성이 안 뜸 — 치는 도중의 글자와 초성 (S5 자동완성)

## 한눈에 보기 (코드 몰라도 OK)
상태: [통과]
무엇이 문제였나: 한글은 치는 도중에 글자 모양이 바뀌어요("디자인"을 치다 보면 "디장"이 돼요). 자동완성은 완성된 글자만 비교해서, 치는 도중이나 초성("ㄷㅈㅇ")으로는 아무것도 안 떴어요. 띄어쓰기로 맞아도 굵게 칠해지지 않았어요.
어떻게 해결했나: 글자를 자모로 풀어서 "자모 앞부분이 맞는지"로 비교해요. 초성만 친 입력은 각 글자의 초성과 비교해요. 그래도 없으면 한영 자판을 바꿔 다시 봐요. 맞은 글자 범위를 원래 문구에 되돌려 굵게 칠해요.

## 개발자 상세

### 증상
S5 전에 자동완성 시험지 19개를 먼저 만들어 쟀어요(S4 코드).

| 유형 | S4 | S5 |
|---|---|---|
| 앞부분·중간 일치·영문·띄어쓰기 (9개) | 100% | 100% |
| 조합 중 ("디장", "해컽", "블렌디") | 0% | 100% |
| 초성 ("ㄷㅈㅇ", "ㅎㅋㅌ" 등 4개) | 0% | 100% |
| 한영 자판 ("gozj", "ㅁㅊㅊㅑ", "qmffps") | 0% | 100% |
| **전체: 목록(6개)에 나옴** | **47%** | **100%** |

### 원인
- `getSuggestions`가 정규화한 문구에서 `includes`로 글자 그대로 찾았어요. "디장"의 "장"은 "디자인" 어디에도 없어요. 사실은 "자" + 다음 글자의 첫소리 ㅇ이에요.
- 초성만 친 입력은 글자가 아니라 자음 낱자라, 완성된 글자와는 비교할 수 없었어요.
- 굵게 칠하기(`splitMatch`)는 원문에서 소문자 `indexOf`로만 찾아서, 띄어쓰기를 무시하고 맞은 경우를 칠하지 못했어요(T-002에서 남긴 일).

### 해결 ([suggest.ts](../../Portfolio/frontend/src/portfolio/suggest.ts) 새 파일)
- 자동완성 코드를 data.ts·notes.ts에서 suggest.ts로 모았어요. 후보는 추천 키워드 → 사례 제목 → 노트 제목 순이고, 같은 문구는 한 번만 넣어요.
- 문구를 글자 하나 = 칸 하나로 나눠요. 공백·문장부호는 칸이 없어요. 칸마다 자모·초성·원래 위치를 기억해요.
- **조합 중**: 입력을 자모로 풀어 칸 시작부터 이어서 맞춰요. 마지막 글자는 앞부분만 맞아도 돼요. "디장"(ㄷㅣㅈㅏㅇ)은 "디자인"(ㄷㅣㅈㅏ + ㅇㅣㄴ)에 맞아요.
- **초성**: 자음 낱자만 2개 이상이면 칸의 초성과 비교해요. 낱말 첫 글자에서 시작할 때만 맞춰요. 처음에는 "ㄷㅈㅇ"이 "모든 작업"의 "든 작업"에 걸려서 이렇게 바꿨어요.
- **한영 자판**: 아무것도 안 맞으면 S4의 자판 변환으로 한 번 더 봐요("gozj" → "해커").
- **정렬**: 문구 맨 앞에서 맞은 것을 먼저 보여 줘요.
- **굵게**: 맞은 칸 범위를 원래 글자 위치로 되돌려 `segments`(굵게/보통)로 돌려줘요. [SearchBox.tsx](../../Portfolio/frontend/src/portfolio/SearchBox.tsx)는 그대로 그리기만 해요.

### 시험지에 맞춘 건 아닌지 확인 (처음 보는 입력 8개)
- S5를 다 만든 뒤 입력 8개(B01~B08)를 정하고 재 보니 7개(88%)가 나왔어요.
- 못 맞힌 1개("ㄹㅇㅇㅅ" → 레이아웃)는 시험지 실수였어요. "웃"의 초성은 ㅇ이고 ㅅ은 받침이에요. 입력을 "ㄹㅇㅇㅇ"으로 바로잡은 뒤에는 8개 모두 나와요. 이 수정은 suggest.json의 memo에 남겼어요.
- 그다음 고친 "낱말 첫 글자에서만 초성 맞추기"는 눈으로 본 잡음 때문이었어요. 고친 뒤에도 19개 + 8개가 그대로 다 나와요.

### 비용
- 속도: 한 글자 칠 때마다 0.05~0.2ms
- 용량: 첫 화면 파일 압축 기준 +0.2KB
- 검색 결과 점수(시험지 39개)는 S4와 같아요(자동완성만 바뀜).

### 남은 것
- 자동완성 후보는 키워드·제목뿐이에요. 본문에만 있는 말("웨이팅")은 제안하지 않아요. 검색 결과에서는 찾아요.
- 한 글자 입력("ㄱ", "디")은 맞는 후보가 많아서 앞쪽 6개만 보여 줘요. 많이 찾는 검색어 순으로 정렬하는 건 검색 기록이 있어야 해서 S7(백엔드)의 몫이에요.

### 배운 것
- 한글 검색은 "완성된 글자"가 아니라 "자모"를 기준으로 생각해야 치는 도중에도 맞출 수 있어요.
- 시험지를 만든 사람도 틀려요. 처음 보는 입력에서 틀린 건, 코드를 고치기 전에 정답부터 맞는지 확인해야 해요.
