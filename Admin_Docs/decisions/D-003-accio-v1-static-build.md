# D-003 Accio 팀 원본은 정적 빌드 결과만 보존

## 한눈에 보기 (코드 몰라도 OK)
상태: [주의] 코드·README에 적힌 이유로 쓴 초안이에요. ❓ 사용자 확인이 필요해요.
무엇을 골랐나: 서버가 닫힌 팀 프로젝트 원본은 **완성된 화면 파일만** `/accio-v1/`에 올리고, 소스(`add_/`)는 레포에 넣지 않았어요.
왜: 원본 소스에는 백엔드 설정과 `.env`가 섞여 있어요. 그래도 당시 화면은 목 모드로 살려서 보여 주고 싶었어요.

## 개발자 상세
- 근거: `Portfolio/frontend/README.md` "Accio v1" 절, `.gitignore`의 `add_/`
- 결과로 생기는 제약: v1을 고치려면 `add_/frontend`에서 빌드한 결과를 `public/accio-v1/`에 다시 커밋해야 해요. 소스를 고친 것만으로는 아무것도 올라가지 않아요.
- 대안: 소스를 정리해서 공개 레포로 올리는 것. 비밀값을 지우는 데 드는 비용이 크고 팀원 동의도 필요해요.
- 바꿔야 하는 조건: 원본 소스를 공개하기로 팀이 합의했을 때
