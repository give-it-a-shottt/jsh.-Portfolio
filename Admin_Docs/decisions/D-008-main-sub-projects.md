# D-008 홈 프로젝트를 메인(대표 3개) · 서브로 나눈다

## 한눈에 보기 (코드 몰라도 OK)

상태: [통과] 사용자 결정(2026-11-19)
무엇을 골랐나: 실제로 배포한 대표 프로젝트 3개(디딤 · Accio · 마에스트로)는 큰 카드로 먼저, 나머지는 '그 밖의 작업' 아래 지금 카드로 보여 줘요.
왜: 카드 8개가 같은 크기로 이어져서, 실제로 돌아가는 풀스택 서비스와 디자인 · 프론트 연습이 구분되지 않았어요(F-015 설계 의도, 사용자 확인).

## 개발자 상세

- 상황: [D-007](D-007-main-study-landing.md)에서 "홈 카드 = `PROJECT_LIST` 전부(대표를 따로 고르지 않음)"로 정했고, F-013에서 `FEATURED_SLUGS`를 지웠어요. 이 결정은 그중 '대표를 따로 고르지 않음'을 바꿔요. 긴 첫 화면 · Main / Study · 피그마 공개 링크는 그대로예요.

| 후보 | 장점 | 단점 |
| --- | --- | --- |
| A. 메인은 큰 카드 3칸, 서브는 지금 카드 (선택) | 대표 3개가 한눈에, 서브는 그대로 촘촘히 | 카드 컴포넌트가 하나 더 생김 |
| B. 카드는 그대로, 제목만 둘로 | 바뀌는 코드가 가장 적음 | 대표와 나머지의 무게 차이가 잘 안 보임 |

- 결정: A (사용자 선택, 2026-11-19). 순서는 디딤 · Accio · 마에스트로(사용자 선택).
- 데이터: `PROJECT_LIST` 하나에 `tier: 'main' | 'sub'`를 두고 메인을 앞에 모아요. 목록을 둘로 나누지 않아서 '다음 프로젝트'가 그대로 한 바퀴로 돌고, `npm run check`가 메인 3개 · 앞쪽 · 첫 번째 디딤을 확인해요. (AI 기재)
- 바꿔야 하는 조건: 대표 프로젝트가 늘거나 줄면 `tier`를 바꾸고, `checks/run.mjs`의 메인 순서 기댓값(사용자가 정한 순서라 고정)도 같이 바꿔요. 메인이 4개를 넘으면 큰 카드 줄을 다시 정해요.
