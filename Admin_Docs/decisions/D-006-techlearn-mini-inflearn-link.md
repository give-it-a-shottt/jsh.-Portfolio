# D-006 techlearn 시안을 지우고 미니 인프런 배포 사이트로 링크만 남기기

## 한눈에 보기 (코드 몰라도 OK)

상태: [통과] 분리 · 예전 주소 처리 · 새 탭 열기 모두 사용자 확인(2026-11-08)
무엇을 골랐나: 포트폴리오 안에서 가짜 데이터로 돌던 techlearn 시안(`#/techlearn`)을 지우고, 같은 디자인을 실제로 만든 미니 인프런(mini-inflearn.vercel.app)으로 링크만 걸어요. Accio(D-005)와 같은 방식이에요.
왜: 사용자가 "포트폴리오 안의 코드는 지우고 링크만 연결"하기로 정했어요(사용자 확인, 2026-11-08).

## 개발자 상세

- 상황: 피그마 「디자인 · 네이비」 시안을 미니 인프런 레포(Next.js + FastAPI + PostgreSQL)로 옮겨 진짜 로그인 · 수강신청에 연결하고 배포했어요(2026-11-08). 포트폴리오의 `src/projects/techlearn/`은 메모리 스토어와 서버 흉내(`api.ts`)로 돌던 같은 화면이라, 두 곳에 같은 프로젝트가 다른 모습으로 있게 됐어요.

| 후보 | 장점 | 단점 |
| --- | --- | --- |
| A. 사이트 안 시안 삭제 + 링크 (선택) | 실제로 동작하는 한 곳만 보여 줌, 코드 약 3,800줄 · 이미지 50여 개가 빠짐 | 예전 `#/techlearn/…` 주소를 처리해야 함 |
| B. 시안 유지 + 링크 추가 | 예전 주소가 그대로 열림 | 목업과 실제 서비스가 함께 보여 헷갈림, 같은 화면을 두 곳에서 고쳐야 함 |

- 결정: A. `App.tsx`에서 techlearn 라우트를 지우고, 배포 주소는 `data.ts`의 `MINI_INFLEARN_LIVE` 한 곳에 둬요. 홈 '진행 중인 프로젝트' 칩이 이 주소를 써요.
- 예전 주소: `#/techlearn`, `#/techlearn/…`는 배포 사이트로 보내요(사용자 결정, 2026-11-08 — 후보는 "배포 사이트로" / "포트폴리오 홈으로"). Accio와 달리 techlearn은 프로젝트 페이지가 없어서 배포 사이트로 바로 보내요. `location.replace`라서 뒤로가기를 눌러도 예전 주소로 돌아와 다시 튕기지 않아요.
- 홈 칩은 사이트의 다른 바깥 링크(`ButtonLink`)처럼 새 탭 + ↗로 열어요(2차 리뷰 R4 제안 수용, 사용자 승인). 예전 주소 판단은 `routes.ts`의 `isOldTechlearnPath()` 한 곳이고 `npm run check`가 검사해요.
- 색 토큰: `index.css`의 `tl-*` 색 · 모서리 토큰도 지웠어요. 다른 화면에서 쓰는 곳이 없음을 검색으로 확인했어요.
- D-001에 주는 영향: "앱 하나 + 해시 라우팅 + lazy"는 그대로예요. 적용 범위가 "포트폴리오 + 마에스트로 · FLASEEK · Nightly"로 줄었어요.
- 바꿔야 하는 조건: 미니 인프런 주소가 바뀌면 `MINI_INFLEARN_LIVE`를 고쳐요. 서비스를 내리면 칩의 href를 빼서 '화면 준비 중' 칩으로 돌려요.
