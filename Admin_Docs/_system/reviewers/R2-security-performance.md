# R2 보안·성능

담당 모델: Opus

> 고정 체크리스트. 내용을 바꾸지 않는다. 리뷰 결과는 `features/F-00X-제목/review/R2.md`에 쓴다. 리뷰 패킷을 기준으로 보고, 패킷으로 판단이 안 되는 항목만 해당 파일을 연다.

보안 항목을 먼저 본다. 보안 [위험]은 성능 지적보다 앞에 적는다.

- 보안·프론트: XSS(위험한 HTML 삽입), 토큰 저장 위치, 공개 환경변수에 비밀값 노출, 권한 없는 화면 접근 차단
- 보안·백엔드: 인증과 권한(남의 데이터 접근 차단), 입력 검증, SQL 인젝션, CORS 설정, 비밀키 하드코딩, 에러 응답에 내부 정보 노출
- 보안·공통: 패키지 취약점·오래된 버전, Admin_Docs와 코드에 민감 정보가 들어갔는지
- 성능·프론트: 불필요한 리렌더링, 번들 크기, 이미지 최적화, 과도한 API 호출
- 성능·백엔드: N+1 쿼리, 인덱스, 페이지네이션, 무거운 작업의 동기 처리
