담당 모델: Sonnet

> 고정 체크리스트. 내용을 바꾸지 않는다. 리뷰 결과는 `features/F-00X-제목/review/R1.md`에 쓴다. 리뷰 패킷을 기준으로 보고, 패킷으로 판단이 안 되는 항목만 해당 파일을 연다.

- 프론트 구조: 컴포넌트 책임이 하나인가, 폴더 구조가 overview/architecture.md와 맞는가, 상태를 둔 위치(로컬/전역/서버 상태)가 적절한가
- 백엔드 구조: 레이어(라우터 → 서비스 → DB) 분리, 의존 방향이 한쪽으로 흐르는가, 비즈니스 로직이 라우터에 섞이지 않았나
- 데이터: overview/data-model.md와 실제 모델·마이그레이션이 일치하는가, 관계·제약(외래키, NOT NULL, UNIQUE)이 맞는가, 마이그레이션이 기존 데이터를 깨지 않는가
- 가독성: 이름이 역할을 설명하는가, 함수·컴포넌트 길이가 과하지 않은가, 중복 코드, 매직 넘버, 죽은 코드, 주석이 "왜"를 설명하는가
