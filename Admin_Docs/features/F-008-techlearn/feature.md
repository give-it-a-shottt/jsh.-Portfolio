# F-008 techlearn 강의 플랫폼 (#/techlearn)

## 한눈에 보기 (코드 몰라도 OK)
상태: [주의] 만들었고 리뷰했어요. 최종 판정 문장을 받는 중이에요.
무엇을: 피그마 techlearn 네이비 시안을 보고 강의 홈 → 목록 → 상세 → 수강신청 흐름을 가짜 데이터로 만들어요. 포트폴리오 홈의 '진행 중인 프로젝트' 칩이 이 페이지로 와요.
왜: 인프런 공고에 올라온 기술을 익히려고 했다는 걸 보여 주려고요.

## 설계 의도 (사용자 확인 — 코드 작성 전에 채움, 문장 정리사 사용)
- 이 기능이 해결하는 문제: 아직 완성은 안 됐지만, 인프런 공고에 올라온 기술을 익히려고 했다는 것을 보여 주려고 만든 페이지다. (사용자 확인)
- 완료 기준(무엇이 되면 끝인지): (사용자 확인)
  - `#/techlearn`에서 강의 홈 → 강의 목록 → 강의 상세 → 수강신청까지 가짜 데이터로 클릭해서 이동할 수 있다.
  - PC와 모바일 화면 모두 피그마 네이비 시안과 맞는다.
  - 포트폴리오 홈의 techlearn 칩을 누르면 이 페이지로 간다.
- 화면·컴포넌트: 피그마 techlearn 「디자인 · 네이비」 페이지의 01 홈, 02 강의 목록, 03 강의 상세, 03-1~03-3 수강신청 (PC·모바일). 나머지 화면은 다음 단계예요.
- API: 없음 — 코드 안 목업 데이터만 써요.
- 데이터: 없음 — DB를 쓰지 않아요.

## 결과 (AI 작성 — 구현 후)
- 위치: `Portfolio/frontend/src/projects/techlearn/` — `TechlearnApp`(라우팅), `screens/`(Home · CourseList · CourseDetail), `lectures.ts`(강의 8개), `data.ts`(홈 홍보 데이터), `store.ts`(포인트 · 수강 기록), `api.ts`(수강신청 서버 흉내), `hooks.ts`(검색 · 수강신청 상태), `enroll.tsx`(확인 모달 · 토스트), `components.tsx`(헤더 · 푸터 · 카드). 색은 `index.css`의 `tl-*` 토큰.
- 주소: `#/techlearn`, `#/techlearn/courses?tab=&q=`, `#/techlearn/course/{id}`. `App.tsx`에 lazy 한 줄과 라우트를 더했고, 포트폴리오 홈 칩을 여기로 바꿨어요.
- 수강신청: 버튼(신청 가능 · 신청 중 · 수강 중, 포인트가 모자라도 누를 수 있음) → 확인 모달(기본 · 포인트 부족이면 충전 · 무료) → 서버 응답 토스트(201 · 409 · 400 · 404 · 500). 포인트 부족 계산은 `hooks.ts` `useEnroll` 한 곳에서 하고, 최종 판단은 `api.ts`가 해요.
- 포인트 충전(리뷰 뒤 사용자 결정): 버튼을 막는 대신 모달 안에서 부족분 · 3만 · 5만 P 중 골라 바로 충전해요. 충전하면 같은 모달이 기본 상태로 바뀌어 바로 신청할 수 있어요(`store.ts` `chargePoints`, 실제 결제 없음).
- 상태는 메모리에만 둬요. 새로고침하면 50,000 P · 2개 수강 중으로 돌아가요.
- 설계 의도와 다른 점
  - 홈 인기 강좌는 원화 가격이고 강의 목록은 포인트라서, 홈 카드는 상세가 아니라 강의 목록으로 보내요.
  - 시안 푸터의 회사 정보(사업자 번호 · 주소)는 실제 회사처럼 보일 수 있어서 "개인 포트폴리오 시안" 안내로 바꿨어요.
  - 커리큘럼 총 시간은 강 길이를 더해 계산해요. 시안의 "총 3시간 40분" 대신 실제 합인 "3시간 2분"이 나와요.
  - '내 강의로 이동' · '내 강의 보기'는 내 강의 화면(09)이 아직 없어서 강의 목록으로 가요.
  - 커뮤니티 · 멘토링 · 장바구니 · 내 학습실은 누르지 않고 '준비 중'으로 보여요. 강의 카드의 찜 버튼도 아직 동작하지 않아요.
  - 시안 03-1의 '포인트가 부족해요' 비활성 버튼과 03-3의 비활성 '신청하기' 대신, 모달에서 충전하게 바꿨어요(사용자 결정).
  - 홈의 '1회차 무료 강의' 버튼과 분야 카드는 강의 목록 전체로 가요.
