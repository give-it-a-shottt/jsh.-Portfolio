### [제안] 중 눈여겨볼 것 (전체는 R1~R7.md)
- 홈 '최근 기록' 설명 "분야별로 최신 글 3개씩"이 실제 규칙(중요도 1위 사례 1개 + 최신 노트 2개)과 달라요. 화면 문구라 사용자가 정할 칸이에요(R6 · R2).
- 포트폴리오 푸터가 홈뿐 아니라 검색 결과 · 상세에도 붙어요. 의도인지 확인이 필요해요(R6).
- 표시 함수 `points` · `rating` · `won`을 한 파일로 모으기, `routes.ts` 주석의 `cat` 예시 고치기(R1 · R2).
- techlearn 홈 후기에 실제 사람처럼 이름 · 경력이 적혀 있어요. "예시 후기" 표시를 붙이자는 제안이에요(R3).
- 썸네일 13장 JPEG → webp(R4). 그림자 직접 값 15종 · `text-[10px]` 토큰 정리(R7). 최근 기록 분야 점 색이 시안과 달라요(R7, F-003).
- api-list.md에 techlearn 흉내 계약(`POST /courses/{id}/enroll`)이 빠져 있어요(R6).
- 피그마 주소가 공개 코드 · 문서에 들어간 점(R3) — 사용자 결정으로 Nightly 칩 · design-link.md · R7.md에서 주소를 모두 지웠어요. Nightly 칩은 화면이 생길 때까지 누르지 않는 이름표예요.
