## 지적 (있을 때)
- [주의] 수강신청 모달을 닫으면 키보드 포커스가 사라짐. Esc · 취소 · 신청하기 어느 쪽으로 닫아도 포커스가 `BODY`로 떨어짐(Playwright로 확인). 그래서 키보드 사용자는 페이지 맨 위부터 다시 Tab 해야 함. 원인: 모달이 React에서 먼저 빠지고 `useEffect` 정리에서 `close()`가 늦게 불려서, 브라우저의 "원래 자리로 포커스 돌려놓기"가 동작하지 않음 — enroll.tsx `EnrollModal` 28~32줄, CourseDetailScreen.tsx 115~117줄 — 모달을 열 때 `document.activeElement`를 저장해 두고, `onCancel`/`onConfirm` 뒤에 그 요소로 `focus()`를 돌려놓음. 또는 `<dialog>`를 항상 렌더해 두고 `confirming` 값에 따라 `showModal()`/`close()`만 부름.
- [주의] 홈 히어로 검색창은 포커스가 가도 아무 표시가 없음. 입력칸에 `outline-none`만 있고 대신 보여 줄 링이 없음(계산된 outline 0, box-shadow 변화 없음). 헤더 검색창은 `focus-visible:ring-2 ring-tl`이 있어서 둘이 다름 — HomeScreen.tsx `Hero` 59~75줄 — form에 `focus-within:ring-2 focus-within:ring-tl`을 주거나 input에 헤더와 같은 링을 줌.
- [주의] 모바일 상세에서 아래 고정 신청 바가 푸터 맨 아래를 덮음. 끝까지 스크롤해도 바(위치 760)가 푸터 끝(844)을 가려서, 일부러 넣은 "개인 포트폴리오 시안으로, 실제 수강·결제가 이루어지지 않습니다" 안내가 보이지 않음(scratchpad r7-mo-bottom.png). `main`의 `pb-28`은 본문만 띄우고 푸터는 그 뒤에 있음 — CourseDetailScreen.tsx 112~113줄 `MobileEnrollBar` · `Footer` — 모바일에서 푸터 아래에 바 높이만큼 여백을 줌(예: 바깥 div에 `pb-[바 높이] lg:pb-0`). 또는 푸터를 바보다 먼저 두고 바 높이만큼 띄움.
