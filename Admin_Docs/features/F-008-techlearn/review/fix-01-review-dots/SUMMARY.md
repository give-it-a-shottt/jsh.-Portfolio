## 개발자 상세
- 위치: [HomeScreen.tsx](../../../../../Portfolio/frontend/src/projects/techlearn/screens/HomeScreen.tsx) `Reviews`
- R1: 상태(지금 점 · 점 개수)는 `Reviews` 안에만 둬요 → 새 파일 · 전역 상태 없음. 스크롤바 숨김은 기존 `scrollbar-none` 유틸리티.
- R2: 외부 입력 · HTML 삽입 없음. 스크롤마다 `setActive`를 부르지만 값이 같으면 React가 다시 그리지 않아요. `ResizeObserver`는 언마운트 때 끊어요.
- R3: 점 개수 = 실제로 멈출 수 있는 자리 수(PC 1280 · 1600은 2개, 900 · 390은 3개), 다 보이면 점을 숨김. Playwright로 폭 4가지에서 점 · 화살표 · 밀기 확인(1→2→1, 1→3→2, 1→3→1). tsc · lint · build 통과. 자동 테스트 없음은 F-008 '다음에 고칠 것'과 같아요.
- R4: 요청("프로그래스 바를 참고 이미지처럼")과 맞아요. 화살표는 그대로 두고 같은 칸 단위로 움직여요. API 변경 없음.
- R5 [제안] 점 높이 8px — 누르는 대상 최소 24×24px(WCAG 2.2) 권장보다 작아요. 모바일은 화살표가 숨겨져 점이 유일한 버튼이에요 — 모양은 두고 누르는 영역만 여백으로 키울 수 있어요.
- R5 [제안] 비활성 점(`tl-weak` 40%) 대비 약 1.7:1 — 조작 요소 3:1(WCAG 1.4.11)에 못 미쳐요. 지금 위치는 긴 막대 모양으로도 구분돼요.
