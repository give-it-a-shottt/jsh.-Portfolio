## 체크 항목별 근거
- 기준 자료(design-link.md 원본) → 열지 않음 → 해당 없음(시각 스타일 변경 없음, href만)
- 토큰 사용 → SearchHome 칩 코드 · index.css 설명 → 칩은 토큰 클래스 그대로, 지운 tl-* 토큰은 쓰는 곳 없음(패킷 서술 기준)
- 컴포넌트 재사용 · 상태 → 기존 칩 그대로, 기본 · 호버 · 준비 중 상태 유지
- screens.md 흐름 · 화면 이동 → 홈 칩 → 배포 사이트, 예전 주소 → 같은 사이트(replace). 문서와 코드 일치
- 반응형 → 칩 레이아웃 변경 없음, 모바일 확인 안 함(범위 밖)
- 키보드 → `<a href>`라 Tab · Enter 동작
- 대체 텍스트 · 폼 라벨 → 장식 점 aria-hidden, 링크 텍스트(이름 + 요약) 있음, 폼 없음
- 색 대비 → 색 값 변경 없음. 기존 칩 대비는 계산하지 않아 미확인(이번 변경과 무관)
- ExternalRedirect → null 한 프레임, 즉시 replace라 문제로 보지 않음
