## 지적 (있을 때)
- [제안] 화면 읽기 프로그램에서 카드 이름이 어색하게 읽힘. ScreenSection 이 `${label} 화면` 을 만들어서 문서 페이지가 "01 Color · Neutral 화면", "08 Button 화면 크게 보기"로 읽힘. 이 사례의 대부분은 화면이 아니라 문서 페이지임. "MO 메인"의 "MO"도 줄임말이라 듣는 사람이 알기 어려움. — data.ts `jsh-design-system` sections 의 label, DesignCaseDetail.tsx ScreenSection·Lightbox 의 alt·aria-label — `DesignSection` 에 이름 뒤에 붙일 말(예: '페이지')을 넣는 칸을 두고 ScreenSection 에 넘김. 또는 label 을 "모바일 메인"처럼 풀어 씀. 영어 이름은 `lang="en"` 로 감싸면(BackLink 처럼) 더 자연스럽게 읽힘.
- [제안] 같은 카드 안에서 페이지 수가 다르게 보임. 설명은 "26개 페이지로 정리", 지표는 "페이지 27장", 표지·목차 칸은 "27개 페이지의 지도". Design 탭 스크린샷에서 두 숫자가 바로 위아래로 보임. — data.ts `jsh-design-system` 의 description·metrics, sections[0].description — 무엇을 셌는지(표지·목차 포함 여부) 정해 한 숫자로 맞추거나, "본문 26 + 표지·목차"처럼 기준을 적음.
- [제안] (기존 문제, 이번 변경 범위 밖) 모바일 카드는 이미지를 통째로 보여줘서 375×2510 'MO 메인' 카드가 아주 김. w-60(240px)이면 약 1,606px, sm:w-70(280px)이면 약 1,874px. 옆 카드(1333·981 높이)와 높이 차가 커서 칸 아래가 비어 보임. FLASEEK 모바일 메인(390×2535)도 같은 방식. — DesignCaseDetail.tsx ScreenSection 모바일 카드 `h-auto` — 모바일 카드에 최대 높이(예: 휴대폰 한 화면 비율)와 `object-cover object-top` 을 주고 전체는 라이트박스에서 보게 함.
- [제안] (기존 문제, 이번 변경 범위 밖) 라이트박스는 이미지를 화면 폭에 맞춰 줄이기만 함. 이 사례는 1440 폭 문서 페이지라 휴대폰(약 343px)에서는 약 24%로 줄어 안의 글자를 읽기 어려움. 2920×960 아이콘 라이브러리는 더 작아짐. 손가락으로 확대(핀치)는 막혀 있지 않음. — DesignCaseDetail.tsx Lightbox `<img>` 의 `maxWidth: min(100%, …)` — 문서 페이지는 "원래 크기로 보기"(가로 스크롤) 버튼을 두는 방법을 검토.
