- XSS → diff 전체 · 새 파일 6개 · 추가 줄 검색 → dangerouslySetInnerHTML · innerHTML · eval 없음, 값은 고정 데이터, 바깥 링크 rel 유지
- 토큰 저장 위치 → 새 저장 없음, 랜딩의 sessionStorage 기록은 코드째 빠짐
- 공개 환경변수 → 새 VITE_ 값 없음
- 권한 없는 화면 → 해당 없음 (정적 사이트)
- 백엔드 보안 전부 → maestro 24개 파일을 대시만 맞춰 비교해 모두 같음 → 해당 없음
- 패키지 → 변경 없음 (취약점 조회는 미확인 - 이번 작업이 패키지를 건드리지 않음)
- 민감 정보(코드 · 문서 · 이미지) → 이미지 9장 직접 확인, 로그인 안 한 화면, geogi 위치는 캡처용 가짜 좌표, EXIF · XMP 없음
- 리렌더링 → 스크롤 값은 MotionValue, 번호가 바뀔 때만 두 글을 다시 그림
- 번들 → 메인 JS 981,944B(+약 39KB), 대신 첫 방문 랜딩 조각 37.1KB가 사라짐
- 이미지 → webp 39~135KB, 섹션 800px 앞에서 약 675KB를 미리 받음(의도와 맞음)
- 움직임 비용 → translate · 색 전환만, 움직임 줄이기면 꺼짐
- API 호출 · 백엔드 성능 → 해당 없음
