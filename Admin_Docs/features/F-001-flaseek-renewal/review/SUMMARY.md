### [제안] 요약 (자세한 내용은 각 R 파일)
- 구조·가독성: 필터 그룹·구매 버튼 중복, `setCount`·`visible`·`ready` 이름, 죽은 코드(`FilterChip.lang`, `addToCart(count)`), `cat` 쿼리 미검증, 스크롤 잠금+Esc 코드 4벌 → `shared/` 훅
- 성능: 스크롤 핸들러를 rAF·IntersectionObserver로, 상세 연출 컷 `loading="lazy"`, 라이트박스 `backdrop-blur` 제거
- 보안: `npm audit` high 3건(vite, source-map-js, zod — 모두 개발 도구, 이 기능이 넣은 것 아님). 별도 커밋으로 처리 권장
- 설계 의도: 정렬 항목이 IA(인기·신상·가격·리뷰)와 다름, 모바일 타입 선택 모양, 메인 BEST 탭 선택값이 '전체 보기'로 안 넘어감, 라이트박스는 F-001 범위 밖 공통 변경 → 문서 기록
- 접근성: 찜 버튼 대비·라벨, 카드 링크 2개, 세트 칩 화살표 키, 토스트 live region, 라이트박스 Tab 가두기
