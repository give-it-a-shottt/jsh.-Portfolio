- 설계 의도와 다른 점
  - 피그마에 없지만 더한 것: 열린 곳이 3곳 미만일 때 "'비 와' 빼면 N곳 더" 칩, 시연 시각을 자동으로 바꿨을 때 안내 줄, '비 와'를 고르면 "날씨는 시연용 가정이에요", PC 상세 패널 Esc 닫기.
  - 투표(VOT)는 완료 기준대로 구현 2차예요. 표로 비교의 [함께 고르기]는 누르지 않는 버튼 + "투표는 다음 버전에서 열려요".
  - 예전 화면이 쓰던 API(`/api/regions` · `/api/situations` · `/api/score` · `/api/places/{id}` · 예약)는 백엔드에 그대로 남아 있지만 새 화면은 부르지 않아요. 자리 물어보기의 답 기다리기만 예전 `GET /api/live-status/{queryId}`를 같이 써요. 예전 API는 2차에 정리해요(사용자 결정, 2026-11-01).
- 1차 리뷰 뒤 고친 것(2026-11-01)
  - real인데 유미 키가 비어 있으면 결과 · 상세는 저장본, 자리 물어보기는 흉내 답으로 동작해요(전에는 전부 502). `deps.py get_live_yumi_client()`.
  - 유미가 실패하면 그 동네는 10분 동안 다시 부르지 않고 저장본으로 가요. 유미는 15초까지만 기다리고, 같은 동네 검색은 한 번에 하나만 나가요. 응답 모양이 이상해도 500이 아니라 저장본이에요.
  - 자리 물어보기 입력: 인원 1~10, 식당 id 64자 이하(영문 · 숫자 · `_` · `-`)만 받아요. 흉내 문의 기록은 10분이 지나거나 1,000개를 넘으면 오래된 것부터 지워요.
  - PC 결과 화면 안내 글자 2개를 text/sub로(대비 4.11 → 8.96). 1024~1199px 가로 스크롤 없앰. 링크형 조건 칩에 '선택됨'을 읽어 줌. 자리 물어보기 시트는 Tab이 시트 안에서만 돌고 초점이 튀지 않아요.
  - 쓰지 않는 프론트 타입 필드(`Picks.day` · `PlaceDetail.address` · `PlaceDetail.conditions` · `Condition.hint`)를 뺐어요.
