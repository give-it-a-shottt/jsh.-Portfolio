## 체크 항목별 근거
- 대비 ① 포커스 링 → #2563eb 흰 배경 약 5.2:1, #f8f4ec 위 약 4.7:1 → 통과
- 대비 ① 호버 · 선택 → 변경 범위 밖, 링은 상태 무관 동일
- 색만으로 의미 → 링은 두께 · 형태로도 구분, 활성 탭은 aria-current + 굵기 + 밑줄
- 대비 ② · ③ → 해당 없음 / 금지 조합 없음
- 토큰 → var(--color-portfolio)
- 키보드 포커스 항상 보임 → 기본 표시를 대체(outline: none 아님), 스크린샷 확인
- 잘림 → 탭은 안쪽 offset, 잘림 없음
- 모서리 → base 레이어라 rounded 유틸리티가 이김(카드 16px)
- 참고 → 검색 input 빛 테두리 대비는 이번 범위 밖
- 컴포넌트 · 반응형 · 대체 텍스트 → 해당 없음 / 변화 없음
