## 체크 항목별 근거
- 로딩·에러·빈 데이터 → 해당 없음 (정적 데이터)
- 네트워크·입력 오류 → 해당 없음
- 날짜·시간대 → daysSinceStart: 로컬 연월일을 Date.UTC로 맞춰 비교 → 문제 없음
- 날짜·서머타임 → UTC 자정끼리 차이 → 문제 없음
- 시작일 이전 → Math.max(0, …) → 음수 없음
- 값 검증 → 30+31+3 = 64, Playwright 64와 일치 → 문제 없음
- 렌더 시점 → STATS 상수 → stats() 함수로 개선, 자정 자동 갱신은 없음(제안)
- 백엔드 → 해당 없음
- 테스트 존재·정상/예외 → 단위 테스트 없음, 정상 경우만 실행 확인(제안)
- 통과 → 패킷의 lint · tsc · build · Playwright 기준 통과
- StudyDetail 문구 삭제 → diff · Playwright → 문제 없음
