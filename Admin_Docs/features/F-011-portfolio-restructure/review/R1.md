- [주의] 프로젝트 데이터 중복·불일치 소지 — projects.ts `links`·`card`·`roles` ↔ data.ts `CASES[].links`·`metrics`·`roles` (Accio 역할이 두 곳에서 다름) — 겹치는 값(배포 주소 등)을 data.ts 상수로 꺼내 함께 쓰거나, 최소한 맞출 것을 주석에 적는다.

- [제안] 매직 문자열 — `project-${id}` 3곳, "마지막 링크 = 주 버튼" 규칙 2곳(ProjectPage · SearchHome), IntersectionObserver rootMargin — `sectionDomId()` · `primaryLink()` 헬퍼와 "왜" 주석.
