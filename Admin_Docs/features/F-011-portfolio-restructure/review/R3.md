## 지적
- [주의] `readTab()`의 `value in LEGACY_TABS`는 프로토타입 키도 true로 본다. `?tab=constructor` 같은 주소면 탭 값 대신 함수가 돌아와 탭 필터가 깨진다(예전 TABS.includes는 안전했음) — routes.ts `readTab` — `Object.hasOwn(LEGACY_TABS, value)`로.
- [주의] 프론트 자동 테스트가 없다. 새 분기(`readTab` 예전 탭, 없는 slug, `#/accio/…` 이동)는 build · lint · 사람 확인뿐 — package.json — `search:eval`처럼 작은 확인 스크립트를 두거나 테스트 부재를 기록.
- [제안] `fromCase()`가 사례를 못 찾으면 모듈 로드 때 throw → 홈까지 흰 화면 — projects.ts `fromCase` — 빌드 시 확인을 두거나 그 줄만 건너뛰기.
- [제안] lazy 청크를 못 받으면 에러 경계 없이 빈 화면(`Suspense fallback={null}`). 기존 방식과 같음 — PortfolioApp.tsx — 후속으로 에러 경계 한 곳.
- [제안] `useActiveSection`이 처음 값만 써서, '다음 프로젝트'로 slug만 바뀌면 이전 섹션이 선택으로 남을 수 있다(스크롤하면 갱신) — ProjectPage.tsx — `<ProjectPage key={slug}>` 또는 effect에서 초기화.
