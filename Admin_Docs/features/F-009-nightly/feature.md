상태: [주의] 만들고 리뷰 · 판정을 마쳤어요. 오류 경계와 자동 테스트는 다음 단계예요.
무엇을: 피그마 「AI 수면」 Design 시안을 보고 Nightly의 홈 · 수면 대시보드 · AI 수면 코치 화면을 가짜 데이터로 만들어요. 포트폴리오 홈의 '진행 중인 프로젝트' Nightly 칩이 이 페이지로 와요.

## 설계 의도 (사용자 확인 — 코드 작성 전에 채움, 문장 정리사 사용)
- 이 기능이 해결하는 문제: 백엔드를 공부하려고 만드는 프로젝트 Nightly의 화면이다. 지금은 피그마 시안을 화면으로 옮기고, 나중에 프로젝트 소개 페이지로 바꾼다. (사용자 확인)
- 완료 기준(무엇이 되면 끝인지): (사용자 확인)
  - `#/nightly`가 열리고, 화면이 피그마 「Design」 시안과 맞는다.
  - 포트폴리오 홈의 Nightly 칩을 누르면 이 페이지로 간다.
- 화면·컴포넌트: 피그마 「AI 수면」 파일의 「Design」 페이지 중 01 홈, 04 수면 대시보드, 05 AI 수면 코치 (PC·모바일). 나머지 화면은 다른 곳에서 완성하므로 여기서는 만들지 않아요. (사용자 확인)
- API: 없음 — 코드 안 목업 데이터만 써요. (사용자 확인)

## 결과 (AI 작성 — 구현 후)
- 위치: `Portfolio/frontend/src/projects/nightly/` — `NightlyApp`(라우팅), `screens/`(Home · Sleep · Coach), `data.ts`(수면 기록 · 그래프 · 코치 답 가짜 데이터), `hooks.ts`(`useCoachChat` — 스트리밍 흉내 · 요청 제한), `components.tsx`(유리 카드 클래스 · 로고 · 헤더 · 푸터 · 점수 링 · 모바일 탭 바), `assets/`(시안에서 내려받은 아이콘 SVG). 색 · 그림자는 `index.css`의 `nt-*` 토큰.
- 주소: `#/nightly`, `#/nightly/sleep`, `#/nightly/coach?q=`. `App.tsx`에 lazy 한 줄과 라우트를 더했고, 포트폴리오 홈 Nightly 칩에 `href`를 붙였어요.
- AI 코치: 서버 없이 미리 써 둔 답을 30ms마다 두 글자씩 늘려 SSE 스트리밍처럼 보여 줘요. 추천 질문 · 직접 입력 · 대시보드 질문 칩(`?q=`)으로 물을 수 있어요. 1분에 5번까지만 물을 수 있고(시안처럼 3/5에서 시작), 넘기면 입력을 막고 429 안내를 보여 준 뒤 1분 뒤에 다시 열어요. 움직임 줄이기를 켠 사용자에게는 답을 한 번에 보여 주고, 화면 읽기 프로그램에는 다 쓴 답만 한 번 읽혀요.
- 화면 폭: 1024px 이상은 PC 시안, 그 아래는 모바일 시안 배치예요. 모바일 대시보드는 아래에 떠 있는 탭 바, 모바일 코치는 헤더 · 푸터 없는 전체 화면 대화예요. 1024~1279px 대시보드는 7일 점수를 한 줄 전체로 놓아요.
- 상태는 메모리에만 둬요. 새로고침하거나 화면을 나갔다 오거나 `?q=`가 바뀌면 대화와 요청 횟수가 처음(3/5)으로 돌아가요.
- 리뷰 뒤 고친 것: 코치 답을 `Object.hasOwn`으로 찾아 `?q=constructor` 같은 주소에도 화면이 깨지지 않아요. 점수 · 비율 · 총 수면은 `data.ts` 한 곳에서 꺼내 써요. 글자 대비 지적(밝은 칸 안 작은 이름표 · 입력창 placeholder)은 일부러 위계를 낮춘 색이라 시안 그대로 둬요(사용자 결정).
- 설계 의도와 다른 점
  - 로그인 · 회원가입 화면이 이번 범위 밖이라, 홈의 로그인 · 회원가입 · 무료로 가입하기는 데모 계정의 수면 대시보드로 보내요.
  - 타임세일 · 정기구독 메뉴, 탭 바의 샵 · 마이, 추천 상품의 '보러 가기'는 다른 곳에서 완성하는 화면이라 누르지 않는 표시(마우스를 올리면 '준비 중이에요')로 둬요. 홈 기능 카드는 수면 데이터 · AI 코치 두 개만 눌러져요.
  - 날짜 이동(‹ ›)은 가짜 데이터가 하루치라 눌리지 않게 해 뒀어요.
  - 수면 단계 그래프는 시안의 막대 위치를 분 단위로 옮겨, 화면 폭에 맞춰 늘어나게 그렸어요. 시간 눈금은 실제 시각 위치에 놓아서 시안보다 조금씩 오른쪽에 있어요.
  - 모바일 헤더의 상태 점 · 알림 · 메뉴는 시안에서 그림 한 장이라, 메뉴 자리에만 투명 버튼을 얹었어요. 메뉴를 누르면 헤더 아래로 목록이 펼쳐져요(시안에는 펼친 모습이 없어요).
