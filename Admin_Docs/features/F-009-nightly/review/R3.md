## 체크 항목별 근거
- 로딩 · 에러 · 빈 데이터 화면 → CoachScreen `Typing` · `list` · `composer` · 요청 제한 → 통과. 점 이미지를 하나로 합친 것뿐, `aria-busy` · sr-only aria-live 영역 그대로
- 429 제한 안내 → CoachScreen 요청 제한 → 통과. `limited` 분기와 문구 그대로, 색만 warning → danger(토큰 있음), 모바일 `{used}/{RATE_LIMIT}` 그대로
- 비활성 버튼 → 보내기 · 추천 질문 · 모바일 빠른 질문 → `disabled={streaming || limited}`와 `disabled:opacity-*` 유지 → 위 [제안]만
- 입력 오류 메시지 → 해당 없음 (QUESTION_MAX · submit · 검증 로직 변경 없음, focus 그림자만 토큰으로)
- 네트워크 실패 · 응답 코드 · 롤백 · 외부 API → 해당 없음 (백엔드 없음)
- 삭제한 토큰 · 상수 참조 누락 → projects/nightly · src grep → 사용처 0, tsc · build 통과로 뒷받침 → 통과
- 테스트 유무 · 정상/예외 → 자동 테스트 없음(1차에서 다음 단계로 미룬 항목). 범위 밖이라 지적하지 않고 기존 보류로 둠
