### [제안] 중 눈여겨볼 것 (전체는 R1~R5.md)
- PC 화면과 모바일 화면을 둘 다 그려 두고 CSS로 숨겨서, 스트리밍 중 30ms마다 대화 목록 두 벌이 다시 그려져요. `Message`를 `memo`로 감싸거나 한쪽만 그리는 방법이 있어요(R2).
- 그래프 막대를 더한 분(깊은 잠 130 · REM 106 · 깨어 있음 15)이 단계 카드 숫자(112 · 98 · 20)와 달라요. 시안 막대 위치를 그대로 옮긴 값이에요(R3).
- 요청 제한 횟수는 화면을 나가거나 `?q=`가 바뀌면 3/5로 돌아가요(R3). 결과 칸에 적었어요.
- 오류 경계가 없어서, 프로젝트 화면 하나가 깨지면 사이트 전체가 하얘져요. 프로젝트 라우트를 오류 경계로 감싸자는 제안이에요(R2 · R3).
- 범위 밖 메뉴의 '준비 중'은 마우스 title로만 보여서, 화면 읽기 프로그램 · 키보드 사용자에게 전달되지 않아요(R5). 공통 `focus-visible` 스타일도 없어요(R5).
- 탭 바 `active`가 글자 라벨이라 키로 바꾸는 편이 안전해요. 범례 순서 직접 적기 · PC/모바일 분기 정리(R1).
- 코치 화면의 `POST /api/v1/coach/stream` 글자는 실제 API를 만들 때 api-list.md와 맞춰야 해요(R4).
- 자동 테스트가 없어요. vitest를 들이면 `useCoachChat`의 경계 입력 · 5/5 · 60초 뒤 해제 · 언마운트 정리부터 테스트하자는 제안이에요(R3).
